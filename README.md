# Aménag'Van

Site vitrine d'Aménag'Van : aménagement et réparation de vans à Mauléon (79).

En ligne : https://amenagvan.github.io

## Contenu
- `index.html` : page d'accueil (services, VASP, tarifs, avis, contact)
- `configurateur.html` : configurateur de projet avec estimation et récapitulatif PDF
- `mentions-legales.html`

## À modifier facilement
- `js/config.js` : e-mail et téléphone de l'atelier
- `js/tarifs.js` : taux horaire et grille de prix (utilisée partout sur le site)
